# Component Specifications

## Launch Components
- Header and mobile navigation.
- Footer.
- Button variants: primary, secondary, ghost, link.
- Form input, textarea, select placeholder.
- Sport card.
- Gallery card.
- Testimonial card.
- Enquiry form.
- Corporate enquiry form.
- CTA band.
- Notification/banner.
- Loading, empty, and error states.

## Future Components
- Availability picker.
- Slot selector.
- OTP form.
- Payment method card.
- Booking summary.
- Admin navigation.
- Admin data table.

## Rule
Repeated UI should become a reusable Figma component first, then a shared implementation component later.
