# Launch Checklist

## Documentation
- PRD approved.
- ADRs accepted.
- Traceability matrix complete.
- Figma handoff approved.

## Product
- Home, Sports, Sport Detail, Gallery, Testimonials, About, Contact, Corporate Events, FAQ complete.
- Contact enquiry works.
- Corporate enquiry works.
- Seed content reviewed and replaceable.
- No live booking, payment, or OTP exposed.

## Quality
- Responsive checks pass.
- Accessibility checks pass.
- Build, lint, typecheck, tests pass.
- No browser console errors.
- API errors are recoverable in UI.

## Operations
- Environment variables documented.
- Database migrations ready.
- Rollback plan documented.
- Monitoring/logging baseline configured.
