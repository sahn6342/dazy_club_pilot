# API Contracts

The API is versioned under `/api/v1`. First launch exposes only public content and enquiry endpoints. Booking, payment, and OTP endpoints are reserved for future phases and must not be enabled until their providers and workflows are approved.

## Launch Contracts
- Sports list.
- Gallery list.
- Testimonials list.
- Notifications list.
- Contact enquiry create.
- Corporate enquiry create.

## Future Contracts
- Availability.
- Booking.
- Payment.
- OTP.
- Admin/CMS.
