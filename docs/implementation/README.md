# Implementation Roadmap

Implementation starts only after documentation is refined and the Figma design is approved.

## Order
1. Initialize git and repo foundation.
2. Scaffold monorepo.
3. Build shared packages.
4. Build design system from Figma.
5. Build public web app.
6. Build API foundation.
7. Add seeded content.
8. Add enquiry persistence.
9. Add tests and CI.
10. Preserve future booking/payment/OTP architecture.

## Launch Target
Public browse + enquiry site. No live booking, payment, or OTP.
