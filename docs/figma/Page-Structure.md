## Pages
Due to the Figma Starter three-page limit, use this structure:

1. 00 Cover & Foundations
   - Cover.
   - Brand direction.
   - Token palette.
   - Launch/deferred scope summary.

2. 01 Components
   - Button components.
   - Sport card.
   - Gallery card.
   - Testimonial card.
   - Enquiry form.
   - Loading, empty, and error states.

3. 02 Screens & Handoff
   - Desktop Home.
   - Mobile Home.
   - Tablet Sports.
   - Public screen frames for Sports, Sport Detail, Gallery, Testimonials, About, Contact, Corporate Events, FAQ.
   - Deferred future booking/OTP/payment frame.
   - Deferred admin shell preview.
   - Implementation handoff notes.
