# Definition Of Done

## Documentation Done
- Launch scope and deferred scope are explicit.
- Requirements map to screens, APIs, entities, and tests.
- ADRs exist for major technical decisions.
- Figma has enough direction to design without guessing.
- Implementation docs describe order, dependencies, and quality gates.

## Figma Done
- New file named Dazy.club - Landing Experience exists.
- Foundations, tokens, components, and public screens are present.
- Mobile, tablet, and desktop frames are represented.
- Future booking, payment, OTP, and admin shell areas are marked deferred.
- Handoff notes match product and architecture docs.

## Code Done
- Typecheck, lint, tests, and build pass.
- Public landing screens match approved Figma design.
- Enquiry forms persist via API.
- Seeded content is replaceable.
- Deferred payment and OTP are behind stable adapter contracts.
- No live booking, live payment, or live OTP is exposed in launch scope.
