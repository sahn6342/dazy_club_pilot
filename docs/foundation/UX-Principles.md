# UX Principles

## UX-001
Booking in under 60 seconds.

## UX-002
Every important action must provide immediate visual feedback.

## UX-003
Dark-first experience with premium feel.

## UX-004
Animations communicate state, not decoration.

## UX-005
Mobile-first. Desktop enhanced.

## UX-006
Calendar interaction inspired by meeting schedulers.

## UX-007
No dead ends. Every page has a clear CTA.

## UX-008
Accessibility AA minimum.
