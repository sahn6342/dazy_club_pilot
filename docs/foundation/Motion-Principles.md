# Motion Principles

| ID | Component | Rule |
|----|-----------|------|
| MOT-001 | Button | 180-220ms hover |
| MOT-002 | Card | Lift + subtle tilt |
| MOT-003 | Modal | Fade + scale |
| MOT-004 | Toast | Slide from bottom-right |
| MOT-005 | Page | Shared fade transition |
| MOT-006 | Navbar | Hide on scroll down, reveal on scroll up |

Animations must remain purposeful and performant.
