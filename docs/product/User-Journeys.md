# User Journeys

## Launch Journey: Visitor Enquiry
1. Visitor lands on Home.
2. Visitor understands Dazy.club positioning and available sports.
3. Visitor opens Sports or a Sport Detail page.
4. Visitor views gallery/testimonials for trust.
5. Visitor submits Contact enquiry.
6. System stores enquiry and shows confirmation.

## Launch Journey: Corporate Event Enquiry
1. Organizer lands on Home or Corporate Events.
2. Organizer reviews event fit and sports options.
3. Organizer submits company, group size, event type, preferred date, and message.
4. System stores enquiry and shows confirmation.
5. Team follows up manually until CRM automation exists.

## Future Journey: Booking
1. Customer selects sport and slot.
2. System checks availability.
3. Customer verifies OTP.
4. System locks selected court/time.
5. Customer chooses payment mode.
6. System confirms booking and sends notification.
