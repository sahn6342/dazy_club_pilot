Home -> Gallery -> Testimonials -> Contact Enquiry -> Confirmation

Home -> Corporate Events -> Corporate Enquiry -> Confirmation

## Future Booking Flow
Sport Detail -> Availability -> Booking -> OTP Verification -> Checkout -> Payment -> Booking Success

## Navigation Rules
- Header links expose Home, Sports, Gallery, Corporate Events, About, Contact.
- Primary CTA routes to Contact or Corporate Events in launch scope.
- Booking CTAs must not imply live booking until booking is implemented.
