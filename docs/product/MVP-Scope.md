# MVP Scope

## First Launch Included
- Home page.
- Sports listing and sport detail pages.
- Gallery.
- Testimonials.
- About.
- Contact enquiry.
- Corporate Events enquiry.
- FAQ.
- Seeded demo content.
- API-backed enquiry persistence.

## Future Included
- Live availability.
- Slot lock.
- Guest OTP.
- Booking checkout.
- Full, partial, and pay-at-venue payment modes.
- Booking confirmation.
- Admin CMS.
- CRM automation.
- Notification campaign management.

## Excluded
- Cafe.
- Membership.
- Wallet.
- Native mobile apps.
- Loyalty program.
- Complex analytics dashboard.

## Rule
If a feature requires live booking, live OTP, or live payment, it is future scope unless explicitly re-approved.
