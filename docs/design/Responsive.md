# Responsive Design

## Required Frames
- Mobile.
- Tablet.
- Desktop.

## Required Responsive Coverage
- Home.
- Sports.
- Sport Detail.
- Contact.
- Corporate Events.

## Rules
- Prevent overlapping and clipped text.
- Keep tap targets large.
- Preserve CTA hierarchy.
- Use stacked layouts on mobile and richer grids on desktop.
- Gallery and card grids must degrade gracefully to one column.
