# Motion System

## Principles
- Motion supports orientation, hierarchy, and polish.
- Avoid motion that blocks content or form completion.
- Respect reduced-motion preferences in implementation.

## Patterns
- Subtle section reveal.
- Hover/focus elevation for cards.
- Button press feedback.
- Form validation transition.
- Gallery media reveal.

## Deferred
Complex booking-step transitions can be designed in future-booking frames but are not required for first launch.
