# Colors

## Palette
- Primary: Gold.
- Background: Near Black.
- Surface: Dark Gray.
- Text Primary: Near White.
- Text Secondary: Muted Gray.
- Border: Low-contrast gray.

## Semantic
- Success.
- Warning.
- Error.
- Info.

## Usage
Gold is for CTAs, key highlights, active states, and premium accents. Do not use gold as large body backgrounds unless contrast remains excellent.
