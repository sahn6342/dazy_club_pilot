# Design Tokens

## Color
- background/base: near black.
- background/elevated: dark gray.
- surface/card: charcoal.
- text/primary: near white.
- text/secondary: muted gray.
- brand/gold: primary accent.
- semantic/success.
- semantic/warning.
- semantic/error.
- semantic/info.

## Spacing
Use a consistent scale for 4, 8, 12, 16, 24, 32, 48, 64, and 96.

## Radius
- small: compact controls.
- medium: cards and inputs.
- large: hero media and feature panels.

## Typography
Display, H1-H6, Body, Caption, and Label styles.

## Motion
Fast for controls, medium for section reveal, slow only for hero/media polish.
